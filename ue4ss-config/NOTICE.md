# Third-party files in this folder

These files make UE4SS work with Phantom Blade Zero (UE 5.7.4, PBZ.exe `CL-301524_JKS-17219`, Steam build 26266538).
They are not part of the game.

- `MemberVariableLayout.ini`, `UE4SS_Signatures/GUObjectArray.lua`, `UE4SS_Signatures/GNatives.lua`
  – Phantom Blade Zero custom game config by [KintaroModding](https://github.com/KintaroModding), submitted to UE4SS as
  [UE4SS-RE/RE-UE4SS#1484](https://github.com/UE4SS-RE/RE-UE4SS/pull/1484). The signature patterns come from the UE4SS
  team's custom game configs (Metal Gear Solid Delta / Split Fiction / Far Far West) in
  [RE-UE4SS](https://github.com/UE4SS-RE/RE-UE4SS), MIT License.

UE4SS itself is not included; the installer downloads it from the official
[UE4SS-RE/RE-UE4SS releases](https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/experimental-latest) (MIT License).
